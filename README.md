# HomesinBelgium.com

Premium Belgium property discovery and living-guide site.

## Included
- Responsive homepage
- Property search/filter interaction
- City discovery section
- SEO-oriented guide section
- Reserved Adsterra placement
- Property professional CTA

## Listing architecture
- Normalized inventory: `data/listings.json`
- Listing contract: `data/listing-schema.json`
- Partner feed specification: `docs/PARTNER_FEED_SPEC.md`
- Partner landing page: `/partners.html`
- Live partner inventory should only be imported under an authorized API, feed, upload or referral arrangement.
